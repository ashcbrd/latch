Why caffeinate isn't enough

caffeinate holds an assertion against idle sleep. Closing the lid is a different signal entirely, and macOS sleeps anyway unless the machine is in clamshell mode with an external display attached. The setting that actually defeats lid-close sleep is pmset disablesleep — and latch wraps it with the safety rails it badly needs.

What it does

Four moving parts, one command.

Survives the lid

Disables lid-close sleep so the machine runs shut, in a bag, exactly as it would open. No external display required.

Watches the battery

A watchdog polls every 60 seconds and restores normal sleep below 20%, so an unattended Mac sleeps cleanly instead of hard-crashing at empty.

Kills the display

Blanks the screen the moment it arms. Nothing is drawn, nothing is wasted, and the machine runs cooler for it.

Puts everything back

Reads your machine's power settings before touching them and restores that exact baseline — not an assumed default — on teardown.

Two commands, really

You'll type the first one before closing the lid and the second when you're back.

latch 
$ latch

latch  arming

  lid-close sleep    disabled
  idle assertion     held
  battery watchdog   armed (restores sleep below 20%)

  Safe to close the lid. Run latch off when you are done.

$ latch off       # restore normal sleep
$ latch status    # check what is active
$ latch --cool    # same, but runs cooler on battery

GitHub · MIT

Disabling lid-close sleep is a persistent system setting. latch off always restores it.
